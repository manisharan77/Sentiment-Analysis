---

## 📌 Project Overview

An end-to-end **Natural Language Processing (NLP)** pipeline that classifies text reviews as **Positive**, **Negative**, or **Neutral** using multiple Machine Learning classifiers.

---

## 🚀 Features

- ✅ Full text preprocessing pipeline (tokenization, stopword removal, stemming, lemmatization)
- ✅ TF-IDF vectorization with unigrams and bigrams
- ✅ Three ML classifiers: Logistic Regression, Naive Bayes, SVM
- ✅ Model accuracy comparison and evaluation
- ✅ Confusion matrix and visualization dashboard
- ✅ Predict sentiment on custom new reviews
